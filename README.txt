# Foodie - Food Ordering Website

A frontend-only food ordering mini project made with HTML, CSS and JavaScript.

## Files
- `index.html` - page structure
- `style.css` - layout, styling and responsive design
- `script.js` - menu filtering, cart, quantity controls, bill calculation and Local Storage

## How to run
1. Extract the ZIP file.
2. Open the `Food-Ordering-Website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet access is required for the remote food photographs.

## Features
- Food categories and menu cards
- Add to cart, increase/decrease quantity, and remove items
- Automatic subtotal, 5% GST, delivery charge and grand total
- Cart saved in browser Local Storage
- Responsive layout for mobile and desktop

## Notes
This is a frontend demonstration. Checkout is simulated; it does not accept payments or send orders to a restaurant.
Delivery charge is ₹30 when the cart is not empty. GST is calculated at 5% of the subtotal.
